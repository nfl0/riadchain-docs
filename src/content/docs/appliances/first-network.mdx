---
title: Create your network
description: Set up a new private network with Manager and the Riadchain wallet, keeping the original network files throughout.
---

Start after [pairing your machine](/appliances/connect-machines/). The current
guided setup starts a single prepared, unconfigured machine. Android Manager
prepares the machine. The separate Riadchain wallet owns the signing keys and
approves the network. Advanced users can [set up without either app](/node/quickstart/).

## 1. Create the request in Manager

On **Machines**, find **Set up a network** and choose **Choose machine**. Select
the intended appliance, choose **Create request**, then **Save setup request**.
Use **Open Riadchain wallet** to continue, or select the saved file in the
wallet's appliance setup screen.

## 2. Back up four accounts in Riadchain

Open the original request in the **Riadchain** wallet. Check that the machine is
the one you intend to start. Confirm the setup and open the recovery phrases when
the wallet asks. Save them offline with their exact labels:

| Account | Initial funding | Purpose |
| --- | --- | --- |
| Network owner | 10,000 RDC | Authorizes the initial machine to produce blocks |
| Backup owner | 10,000 RDC | Retains independent funded recovery authority |
| Spending account | 100 RDC | Everyday transfers, transactions and fees |
| Backup spending account | 100 RDC | An independent funded account for spending |

The wallet creates all four keys. Write down each phrase before choosing
**I saved all four phrases offline**. Manager never needs these phrases.
The operations key that reaches the appliance cannot spend from the owner account.

## 3. Review the network definition

| In this app | Choose | Open the saved file in |
| --- | --- | --- |
| Riadchain | **Save network plan** | Manager: **Import network plan** |
| Manager | **Save network definition** | Riadchain: **Import prepared genesis** |
| Riadchain | **Sign network setup**, then **Save signed setup** | Manager: **Import signed setup** |

The wallet checks the prepared definition against the original request and
accounts. Confirm the intended machine and genesis before signing. The signed
setup includes public network information and operational credentials encrypted
for that machine.

The one-machine network verifies FILE bytes locally and needs no peer
acknowledgement before publication. This policy is part of signed genesis.
Keep verified backups of active FILE bytes separately.

## 4. Prepare and start

In Manager, review **Prepare machine** and authorize it on the phone. Use
**Check setup status** until preparation succeeds. Then choose **Start network**,
authorize it and check the saved status again. When Manager reports **Network
running**, refresh the machine and verify that the expected network is ready.

The wallet keeps the network's connection details with the saved setup. Verify
the expected connection and an advancing block height before sending funds.
If the machine's endpoint changes later, edit the connection to use the new
trusted address.

## 5. Keep the setup record

Choose **Done** after the original start succeeds. Keep the signed setup,
network identity and four phrase backups. An unknown result calls for
[checking the original request](/appliances/updates-and-help/#when-an-operation-is-uncertain).
Use the same files and keys while reconciling it.
